# 챔피언스 조건부 기술 처리 규칙

2026-11-20 기준 계산기 설계다. 챔피언스 싱글에서 한 포켓몬당 선택한 기술 하나로 데미지와 KO를 계산한다. 기술명은 [챔피언스 한글명 사전](move-names.ko.json) 표기를 따른다.

- **타격**은 기술 사용 중 데미지가 들어가는 한 번을 뜻한다. **1회 결과**는 기술을 한 번 사용한 결과로, 데미지 범위·난수·한 번 사용으로 KO할 확률을 표시한다.
- 반복 KO는 양쪽에 입력한 시작 HP에서 시작하고, 선택 기술이 성공적으로 적중한 사용 횟수로 계산한다. 시작 HP는 1~100%이며 기본값은 100%다. 명중률, 급소 발생률, 확률 부가효과, 턴 종료 피해, 회복, 반동으로 인한 기절은 KO 확률에서 제외한다.
- 반복 계산 중 바뀐 HP·도구·랭크·필드는 같은 상대와의 해당 계산 안에서 유지한다. 화면에 입력한 시작값과 다른 상대의 비교 조건은 그대로 둔다.
- 한 기술에 여러 규칙이 적용되기도 한다. 스케일샷은 **적중 횟수 선택**과 **확정 랭크 변화**를 함께 적용한다. 아이언롤러는 **필드 제거**와 **1회 결과 제한**을 함께 적용한다.

## 1. 사용자가 별도로 입력하는 기술

| 기술                                                                                 | 입력                        | 기본값 | 처리와 예외                                                                                                    |
| ------------------------------------------------------------------------------------ | --------------------------- | ------ | -------------------------------------------------------------------------------------------------------------- |
| 본러시, 씨기관총, 고드름침, 바늘미사일, 록블라스트, 스케일샷, 스위프뺨치기, 물수리검 | 실제 적중 수 2~5회          | 5회    | 선택한 횟수를 매 사용에 적용한다. 스킬링크처럼 횟수가 정해지는 조건은 자동으로 적용한다.                       |
| 트리플악셀                                                                           | 실제 적중 수 1~3회          | 3회    | 첫 타격부터 위력 20 → 40 → 60을 차례로 적용한다.                                                               |
| 찍찍베기                                                                             | 실제 적중 수 1~10회         | 10회   | 실제 적중 수만 선택한다. 타격마다 빗나갈 확률은 별도로 계산하지 않는다.                                        |

**고정 2회 타격** 기술은 **더블어택, 드래곤애로, 더블윙, 트윈빔**이다. 횟수 입력 없이 각 타격을 순서대로 계산한다.

### 위력 2배 토글

아래 일곱 기술의 토글은 모두 **기본 OFF**다. ON이면 해당 비교의 모든 사용에서 강화 위력을 쓴다. 상태는 조건의 주체에 따라 포켓몬 설정에 두거나 상대별로 둔다.

| 기술                     | 토글이 뜻하는 조건                      | 공유 범위   |
| ------------------------ | --------------------------------------- | ----------- |
| 분함의발구르기, 열불내기 | 직전 기술이 실패함                      | 기술 사용자 |
| 분풀이                   | 사용자의 랭크가 그 턴에 내려감          | 기술 사용자 |
| 돌림노래                 | 강화 위력으로 공격하는 상황을 직접 선택 | 기술 사용자 |
| 변덕레이저               | 위력 2배 분기를 직접 선택               | 기술 사용자 |
| 승부굳히기               | 이 상대가 그 턴에 이미 데미지를 받음    | 상대별      |
| 눈사태                   | 이 상대의 공격을 먼저 맞음              | 상대별      |

### 상대 기술이 필요한 반사 기술

| 기술               | 입력                  | 기본값           | 처리와 예외                                                         |
| ------------------ | --------------------- | ---------------- | ------------------------------------------------------------------- |
| 카운터, 미러코트   | 상대 개체와 상대 기술 | 상대 기술 미선택 | 해당 상대에게서 받는 물리·특수 데미지를 각각 계산해 2배로 반사한다. |
| 메탈버스트, 앙갚음 | 상대 개체와 상대 기술 | 상대 기술 미선택 | 해당 상대에게서 받는 데미지를 계산해 1.5배로 반사한다.              |

상대 기술이 비어 있으면 그 상대 행에 기술 선택을 안내한다. 방어 비교를 따로 선택할 필요는 없다. 받는 데미지의 난수를 연결해 **1회 결과**를 표시한다.

## 2. 이미 입력한 값으로 자동 판정하는 기술

모두 기술 전용 입력이나 별도 기본값 없이 아래의 기존 설정을 참조한다.

| 사용자의 수면               | 코골기                                   | 선택하면 사용자의 기존 상태이상을 해제하고 수면으로 교체한다. 선택 중에는 수면으로 고정하며 이전 상태는 복원하지 않는다.                                                                                                         |
| 상대의 상태이상             | 병상첨병, 백귀야행                       | 상대에게 상태이상이 있으면 위력 2배.                                                                                                                                                                                             |
| 상대의 독·맹독              | 베놈쇼크, 독침천발                       | 상대가 독 또는 맹독이면 위력 2배.                                                                                                                                                                                                |
| 사용자의 남은 HP            | 분화, 해수스파우팅, 바둥바둥, 기사회생   | 분화·해수스파우팅은 HP가 높을수록, 바둥바둥·기사회생은 HP가 낮을수록 강해진다. 선택한 시작 HP를 사용하며 사용자 반동이나 상대의 반격은 진행하지 않는다.                                                                          |
| 상대의 남은 HP              | 하드프레스                               | 타격 후 줄어든 상대 HP로 다음 데미지를 다시 계산한다. 난수마다 달라지는 남은 HP를 반영한다.                                                                                                                                      |
| 사용자의 HP 실수치          | 목숨걸기                                 | 사용자의 현재 HP만큼 고정 데미지. 선택한 시작 HP 기준으로 1회 결과만 표시한다.                                                                                                                                                   |
| 상대의 공격 / 사용자의 방어 | 속임수, 바디프레스                       | 속임수는 상대의 공격과 해당 공격 랭크를, 바디프레스는 사용자의 방어와 해당 방어 랭크를 사용한다.                                                                                                                                 |
| 상대의 방어 및 방어 랭크    | 사이코쇼크, 성스러운칼, DD래리어트       | 사이코쇼크는 특수방어 대신 방어를 참조한다. 성스러운칼·DD래리어트는 상대의 방어 랭크 변화를 무시한다.                                                                                                                            |
| 양쪽 능력치                 | 셸암즈                                   | 랭크 적용 후 물리·특수 정수 판정값을 비교한다. 동점이면 물리와 특수를 각각 50%로 표시하고 두 데미지 범위·난수를 보여준다.                                                                                                        |
| 양쪽 최종 스피드            | 일렉트릭볼, 자이로볼                     | 양쪽 스피드 비율에 따라 위력이 변한다. 마비·검은철구 등 실제 스피드 보정을 적용한다. 트릭룸은 스피드 실수치를 바꾸지 않는다.                                                                                                     |
| 사용자 랭크                 | 어시스트파워, 기어오르기                 | 상승한 랭크를 합산해 위력을 정한다.                                                                                                                                                                                              |

| 상대 타입                   | 프리즈드라이, 플라잉프레스               | 프리즈드라이의 물 타입 약점 판정과 플라잉프레스의 격투·비행 상성 결합을 적용한다.                                                                                                                                                |
| 사용자 레벨                 | 나이트헤드, 지구던지기                   | 상성이 유효하면 레벨 50 기준 50 고정 데미지.                                                                                                                                                                                     |
| 사용자·상대의 도구          | 애크러뱃, 폴터가이스트                   | 애크러뱃은 사용자가 무도구일 때 위력 2배. 폴터가이스트는 상대가 도구를 가지고 있어야 한다.                                                                                                                                       |
| 사용자가 던질 도구          | 내던지기                                 | 보유 도구로 위력을 자동 결정한다. 도구 없음·투척 불가 도구·전용 메가스톤·서투름이면 **사용 불가**로 표시한다. 필드에 맞는 시드는 투척 전에 소모되어 사용 불가. 적중 후 도구의 추가 효과와 재획득은 제외하고 1회 결과만 표시한다. |
| 사용자의 타입               | 불사르기, 전광쌍격                       | 각각 사용자에게 불꽃·전기 타입이 있어야 한다. 1회 결과만 표시한다.                                                                                                                                                               |

셸암즈는 첫 타격 전에 분류를 정한다. 이후 도구·특성·랭크로 능력치가 변해도 물리 경로는 끝까지 물리, 특수 경로는 끝까지 특수로 계산한다. 동점이면 두 경로의 시작 확률이 각각 50%다. 반복 KO 구현 시에도 같은 비교의 후속 사용에 이 규칙을 적용한다. 입력을 바꿔 새 비교를 시작하면 분류를 다시 정한다.

상태이상은 포켓몬별 하나를 선택하며 기본값은 **없음**이다. 근성·이상한비늘·속보를 고르면 화상 토글이 기본 ON이다. 근성 발동 중에는 물리기에 화상 반감을 적용하지 않는다. 직접 끄면 상태이상이 해제되고, 다른 상태를 고르면 그 상태 하나만 적용한다. 같은 입력을 기술·특성·스피드 비교에 공유하고, 사용 중 자동 상태 부여·치료는 제외한다. 포이즌힐은 턴 종료 회복 특성이므로 원본 도감에만 보관한다. 계산용 특성 선택지와 자동 독 설정에서 제외한다.

### 날씨·필드·중력

상대별 날씨·필드·중력 설정을 공격·방어·스피드 비교에 공유한다. 접지가 필요한 효과는 현재 타입, 부유 특성, 풍선, 검은철구, 중력 등 해당 비교 조건에서 판정한다. 검은철구를 든 부유·천정부지 포켓몬은 중력이 꺼져 있어도 땅 기술에 맞는다.

| 기술                                         | 참조 조건                | 처리와 예외                                                                                              |
| -------------------------------------------- | ------------------------ | -------------------------------------------------------------------------------------------------------- |
| 웨더볼                                       | 날씨                     | 해당 날씨의 타입과 위력 보정을 적용한다.                                                                 |
| 솔라빔, 솔라블레이드                         | 날씨                     | 비·모래바람·눈에서 위력을 줄인다. 쾌청의 충전 생략은 KO의 기술 사용 횟수와 별개다.                       |
| 대지의파동                                   | 필드와 사용자 접지       | 접지한 사용자는 필드에 따라 타입과 위력이 변한다.                                                        |
| 라이징볼트                                   | 일렉트릭필드와 상대 접지 | 일렉트릭필드에서 상대가 접지하면 위력 2배.                                                               |
| 와이드포스                                   | 사이코필드와 사용자 접지 | 사이코필드에서 사용자가 접지하면 기술의 위력 증가를 적용한다.                                            |
| 미스트버스트                                 | 미스트필드와 사용자 접지 | 미스트필드에서 사용자가 접지하면 위력이 오른다. 사용자 기절 기술이라 1회 결과만 표시한다.                |
| 지진, 땅고르기                               | 그래스필드와 상대 접지   | 그래스필드에서 접지한 상대에 대한 데미지 감소를 적용한다.                                                |
| 그래스슬라이더                               | 그래스필드와 사용자 접지 | 그래스필드에서 사용자가 접지하면 우선도 +1로 선제공격 차단 여부를 판정한다. 필드의 위력 보정도 적용한다. |
| G의힘                                        | 중력                     | 상대별 중력 토글이 ON이면 위력 1.5배. 중력 기본값은 OFF다.                                               |
| 공중날기, 뛰어오르기, 플라잉프레스, 무릎차기 | 중력                     | 중력 ON이면 **사용 불가**. 데미지 0과 사유를 표시한다. 중력의 명중률 상승은 제외한다.                    |
| 아이언롤러                                   | 필드                     | 필드가 없으면 데미지 0과 사용 불가 사유를 표시한다. 필드가 있으면 1회 데미지를 계산한다.                 |

## 3. 타격 전후 상태를 바꾸는 기술

| 기술                         | 입력과 기본값         | 처리와 예외                                                                                                                                                                                    |
| ---------------------------- | --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 깨트리기, 사이코팽, 레이징불 | 기존 상대별 벽 설정   | 데미지를 계산하기 **전에** 상대의 리플렉터·빛의장막·오로라베일을 제거한다. 첫 타격부터 제거된 조건을 사용한다.                                                                                 |
| 아이스스피너, 아이언롤러     | 기존 상대별 필드 설정 | 성공한 타격 **후에** 필드를 제거한다. 아이스스피너의 다음 사용부터 제거된 상태를 반영한다. 아이언롤러는 1회 결과까지만 표시한다.                                                               |
| 탁쳐서떨구기                 | 기존 상대 도구 설정   | 제거 가능한 도구가 있으면 첫 사용에 위력 보정을 적용하고, 타격 후 도구를 제거한다. 다음 사용부터 도구가 없는 상태로 재계산하고 전후 결과를 구분한다. 제거 불가 도구·점착은 해당 규칙을 따른다. |

같은 공격자가 같은 상대에게 같은 기술을 반복하는 계산에서는 벽을 깨는 기술과 공격자의 틈새포착 모두 첫 타격부터 매 타격에 벽 보정을 생략한다.

### 확정 랭크 변화

**랭크 변화 반영 토글은 기본 ON**이다. ON이면 기술별 시점에 확정 효과를 반영한다. OFF이면 입력한 시작 랭크를 유지한다. 러스터캐논처럼 확률로 발동하는 랭크 변화는 누적하지 않으며, 해당 상황을 보려면 시작 랭크를 직접 입력한다.

| 시점                | 바뀌는 랭크                 | 기술                                                                             |
| ------------------- | --------------------------- | -------------------------------------------------------------------------------- |
| 데미지 전           | 사용자 특공 +1              | 일렉트로빔, 메테오빔                                                             |
| 적중 후             | 사용자 특공 +1              | 플레어송                                                                         |
| 적중 후             | 사용자 특공 -2              | 용성군, 리프스톰, 오버히트, 골드러시                                             |
| 적중 후             | 사용자 방어 +1              | 배리어러시                                                                       |
| 적중 후             | 사용자 방어 -1              | 스케일노이즈                                                                     |
| 적중 후             | 사용자 방어·특방 -1씩       | 아머캐논, 인파이트, 들이받기                                                     |
| 적중 후             | 사용자 공격·방어 -1씩       | 엄청난힘                                                                         |
| 적중 후             | 사용자 스피드 +1            | 아쿠아스텝, 오라휠, 니트로차지, 고속스핀, 개척하기                               |
| 적중 후             | 사용자 스피드 -1            | 암해머, 아이스해머                                                               |
| 기술의 연속 타격 후 | 사용자 방어 -1, 스피드 +1   | 스케일샷                                                                         |
| 적중 후             | 상대 공격 -1                | 천추지한, 와이드브레이커, 찬물끼얹기, 덤벼들기, 트로피컬킥                       |
| 적중 후             | 상대 방어 -1                | 불꽃채찍, G의힘                                                                  |
| 적중 후             | 상대 특공 -1                | 매지컬플레임, 엄습하는일격, 바크아웃, 소울크래시, 벌레의저항                     |
| 적중 후             | 상대 특방 -1                | 사과산                                                                           |
| 적중 후             | 상대 특방 -2                | 애시드봄, 루미나콜리전                                                           |
| 적중 후             | 상대 스피드 -1              | 땅고르기, 드럼어택, 일렉트릭네트, 얼어붙은바람, 로킥, 머드샷, 달려들기, 암석봉인 |
| 첫 데미지 계산 후   | 상대 랭크 전부 0으로 초기화 | 클리어스모그                                                                     |

일렉트로빔·메테오빔의 특공 상승은 ON일 때 첫 데미지에도 적용한다. 클리어스모그는 첫 타격에 입력한 상대 랭크를 사용하고, 성공 직후 초기화한 랭크를 다음 사용부터 적용한다. **마지막일침**은 상대를 쓰러뜨린 뒤에 공격이 오르므로 현재 상대의 KO가 끝나면 해당 상승을 계산에 이어 가지 않는다.

### 타격 단위로 공통 적용하는 도구·특성

| 조건             | 처리                                                                                                                                                 |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| 반감열매         | 도구 목록에서 하나의 옵션으로 선택한다. 실제 기술 타입과 발동 조건에 맞는 첫 타격에만 반감과 소모를 적용한다. 소모 전후 데미지·난수를 나눠 표시한다. |
| 노말주얼         | 첫 발동 기술 사용 전체를 1.3배로 강화한 뒤 소모한다. 연속기라면 그 사용의 모든 타격을 강화한다. 강화된 첫 사용과 소모 후 결과를 나눠 표시한다.       |
| 하양허브         | 랭크 변화 반영 ON에서 음수 랭크가 생기면 0으로 되돌리고 한 번 소모한다.                                                                              |
| 풍선             | 효과를 받는 첫 타격 뒤에 터진다. 풍선 때문에 땅 기술이 무효인 경우에는 유지한다. 터진 뒤부터 접지·필드를 다시 판정한다.                              |
| 멀티스케일       | 최대 HP에서 적용한다. 첫 타격으로 HP가 줄면 남은 타격에는 새 HP 상태를 사용한다.                                                                     |
| 기합의띠, 옹골참 | 최대 HP에서 쓰러질 데미지를 받으면 HP 1로 생존하는 조건을 반영한다. 기합의띠는 실제 발동할 때 소모하고, 연속기의 다음 타격은 생존 후 HP로 계산한다.  |
| 탈               | 온전함 기본 ON. 발동하면 첫 타격을 흡수하고 파괴에 따른 최대 HP 1/8 손실을 적용한다. 다음 타격은 깨진 상태로 계산한다.                               |

## 4. 성공 조건을 가정하거나 결과를 1회로 제한하는 기술

| 구분                     | 기술                                 | 입력·기본값·예외                                                                                |
| ------------------------ | ------------------------------------ | ----------------------------------------------------------------------------------------------- |
| 성공 조건 충족 가정      | 기습, 힘껏펀치, 기선제압             | 해당 기술이 성공하는 상황으로 계산한다. 상대 행동·피격·우선도 성공 여부를 따로 입력받지 않는다. |

## 5. 직접 데미지는 계산하고 부수 효과는 범위에서 빼는 기술
